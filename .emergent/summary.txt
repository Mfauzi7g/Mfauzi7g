<product_requirements>
The goal is to build a comprehensive parental control application. The core of the application is a web-based dashboard for parents.

**Phase 1: Core Dashboard (Completed)**
- Create a web dashboard that visually clones the Apple Screen Time interface.
- Display screen time analytics for multiple children in a family.
- Implement a mock in-app purchase system with monthly and yearly subscription tiers.

**Phase 2: Reward System (Completed)**
- Introduce a gamified rewards system.
- Parents can create and assign real-world tasks (e.g., chores, homework) to their children.
- Upon task completion, children earn a specified amount of extra screen time, which is added to a time bank they can redeem.

**Phase 3: Real Device Control (System Built, Deployment Pending)**
- The web dashboard must be able to send real-time commands to control children's devices.
- This requires companion mobile apps (iOS/Android) to be installed on the children's devices.
- The system must support features like setting app time limits, scheduling device downtime, and an emergency unlock function.
- A secure device pairing mechanism (e.g., 6-digit code) is required to link a child's device to the parent's account.

**Phase 4: Family Chat & Subscription Update (Completed)**
- Implement an in-app, real-time chat feature for communication between parents and children.
- Revise the subscription model from a single family plan to a per-child pricing structure: .99/month per child and 9.99/year per child.
</product_requirements>
